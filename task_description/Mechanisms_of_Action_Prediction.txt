Task Name: Mechanisms_of_Action_Prediction

[Task Overview]
- Task Type: tabular multi-label classification
- Modality: structured tabular data (gene expression features + cell viability features + treatment metadata)
- Downstream Goal: predict the probability of each mechanism-of-action (MoA) label for a treated sample.
- Target Columns: multiple binary MoA label columns (0/1), one column per MoA class
- Evaluation Metric: Mean Log Loss (averaged across MoA targets)
- Note: the test split in this dataset also contains labels.
- Objective: train a high-performing model that generalizes well to unseen samples for this MoA prediction task.

[Dataset Details]
- Format: CSV
- Files (brief):
  - Features files: contain sig_id, cp_type, cp_time, cp_dose, g-* (gene expression), and c-* (cell viability) columns.
  - Label files: contain sig_id and multiple binary MoA target columns (0/1), one column per MoA class.
  - Drug ID files: contain sig_id and an anonymized drug_id identifier.
