# Generated Reports

This directory stores generated task reports and LLM-as-a-judge evaluation files.

- `report/`: generated report PDFs for benchmark tasks.
- `Report Judgment/`: archived LLM judge PDF files kept for reference.
- `Report Judgment Score/`: current LLM-as-a-judge scoring files, including prompts, score JSON files, summary CSV files, and the scoring script.

Notes:

- Missing task reports `T3.pdf`, `T11.pdf`, `T12.pdf`, and `T17.pdf` were added to `report/`.
- Local system files such as `.DS_Store` are not included.
