# Generated Reports

This directory stores generated task reports and LLM-as-a-judge evaluation files.

- `report/`: generated report PDFs for benchmark tasks.
- `LLM-as-a-judge/`: current LLM-as-a-judge scoring files, including prompts, score JSON files, summary CSV files, and the scoring script.
- `old/`: archived previous LLM judge PDF files kept for reference.

Notes:

- The current `LLM-as-a-judge/` folder was copied from `/Users/lwb/Downloads/LLM-as-a-judge`.
- Local system files such as `.DS_Store` are not included.
